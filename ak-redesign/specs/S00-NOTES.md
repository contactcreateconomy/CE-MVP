# S00 Foundation — founder notes

## Look and feel
- **Base: Reddit's simple style.** Coupled with **Threads' trends** and **X's performance** in the frontend.
- **Nothing should be disturbing.** Serving the purpose is the first priority.
- **Glow stays, with a reason: "a blink with a reason."** Many AI apps glow, and our audience likes it flashy. Don't over-apply it everywhere. Every animation or glow serves a purpose: something we want to propagate.
- **Glass: subtle, like the Threads tab bar.** Use the Apple (heavy frosted) style only when needed.

## Themes
- **Keep both dark and light.** The code already has both; we just need to polish them.

## Navigation
- **Tab bar unchanged:** Home, Search, Create, Alerts, Profile.
- Profile tab opens my own profile (D-010).

## What must feel premium from day one
- **Feed:** it's where people land first.
- **Discussion:** what they see next.
- **Publishing:** finally.
- "For me it is everything."

## How I decide taste
- I can't make absolute decisions from text. I decide **screen by screen, in the browser, with the app running**, editing each block and seeing it in real time.
- References (Mobbin, Claude Design) are welcome when they help us understand flows.

## Launch
- Users test only when **all user-facing features work as designed**, and the security checks pass. The admin console can be built during beta testing.
- We are selling an experience, not new functionality. No prototype ever goes to users.
