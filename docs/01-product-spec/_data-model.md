# DECISION — Data-Model Bible (Createconomy) · LIVING single source of truth

**Status:** LIVING (seeded by Module 1; each module adds/refines its tables here) · **RACI:** R/A = Opus · Consulted/Informed = GPT/GLM/Sonnet + Founder · **Date:** 2026-07-28
**This is the LOGICAL model** — canonical entity names, relationships, attributes (meaning), enums. It is the single source of truth. The **PHYSICAL model** lives in Convex `schema.ts` (`defineTable` + validators → generated types = runtime enforcement). Module sheets reference the names here; they never re-invent them. Fields deepen in each owning module's sheet; entities/relationships/enums here are authoritative.

## Locked structural principles (from Module 1 rulings + convergences)
- **users is merged** (identity + public profile in one table); a `privateUserData` table is reserved for future sensitive data (billing/PII), split by *sensitivity*, not presentation. `[B1]`
- **Multi-role via `roleAssignments`**; `visitor` is a request state, NOT a stored role. Registered user is implicitly a member.
- **`post.status` is three orthogonal axes:** `lifecycleStatus` · `moderationStatus` · `visibility`.
- **Authorship is explicit:** `authorType` + `authorUserId?` + `authorPersonaId?` + `editorialByline?` with invariants.
- **Ratings = per-user records + aggregate fields on `tools`** (v1). `[B3]`
- **Post types = shape in code + per-type extension tables; state (active/locked) in `postTypeConfig`** — every one of the 10 types is admin-toggleable. New types are **additive** (registry entry + extension table + block component + composer block + optional mechanic table) — **no core surgery; no DB-defined types.** `[M4]`
- **Tool ratings feed the community aggregate; editorial/persona verdicts are display-only** (`postReviews.verdictScore`) and **NEVER** feed the aggregate. **No platform actor** — persona (no userId) or any privileged-role user — may write an aggregate-eligible `toolRating` (server-rejected). `[M4]`
- **No user-authored URLs** in post bodies or comments (server-*rejected*, not silently stripped); platform-injected links only. **Sole exception:** Showcase `projectUrl` (validated + domain-allowlisted + operator-approved). `[M4]`
- **System content = claims-first pipeline** (M2/M3): extract atomic `sourceClaims` → synthesize ORIGINAL narrative from claims (never source prose) → a **deterministic** similarity + traceability gate (**the LLM NEVER decides the hard gate**) → operator approval. **Grounded citation:** every factual assertion cites `sourceClaimId[]` (`draftClaimRefs`); numbers/dates/quotes/entities exact-validated; operator confirms entailment; **embedding = retrieval only, not proof**. **Quotation gate:** quotes are capped (words/quote, quotes/post, % of body) + exact-span + attribution, else re-enter the similarity gate. **SSRF-safe ingestion:** resolve + validate every fetch IP (block private/link-local/loopback/metadata), HTTPS-only, revalidate redirects, cap size/hops, isolated egress. `[M2/M3]`
- **No auto-publish to external platforms** — `postSocialDerivatives` are export-only (DEC-O07). `[M2]`
- **Schema-rating integrity** — SEO `AggregateRating`/review structured data reflects ONLY community `tools.ratingSum/ratingCount`, **NEVER** an editorial verdict (SEO extension of DEC-M5-AGG). `[M2]`
- **Personas = ambient, memory-grounded participants that know when NOT to speak** (M8): default-to-silence; genome = cognitive style (NOT fictional biography); backstory NEVER enters the generation prompt; memory preserves PERSPECTIVE not FACT (facts revalidate vs source claims + tools); excluded from ranking + human counts; humor/sarcasm are configurable dials (default conservative; sarcasm at ideas, never people). `[M8]`
- **Persona lifecycle is public + honest** (M8): birth→active→waning→retired, shown on a public Population page; community revival restores the SAME character with full memory + full lifecycle history (transparent "revived by community"); **revival demand is eligibility-gated (posting trust tier + account age + rate-limit) + operator-confirmed + tally-snapshotted + re-activation-QA'd**; real timestamps, no deceptive human-arrival simulation. `[M8]`
- **Discussion engine = MIN + MAX** (M6): MIN = comments + ranking; MAX = a grounded, navigable **discussion map** (summary/themes/positions/**common-ground + divergence**/Q&A/evidence/nav) — AI-computed (M2 infra), incremental, LABELED, **ENTAILMENT-verified by an independent pass** (spans + {supported|contradicted|insufficient}; discard the whole artifact if any claim is not supported), **personas excluded at input** from themes/common-ground/counts. Presentation-only toggle; one canonical URL. `[M6]`
- **Comment ranking** (M6): **Best = a Bayesian confidence-damped positive score** (category-scoped prior; **NOT Wilson**; exactly one reaction type is the numerator; context never lowers Best); Live = engagement × time-decay; Most-Discussed = volume × balance; Q&A = accepted + Best. **No downvote.** Scores = **projections** off authoritative events (same-mutation deltas + idempotency + reconciliation); realtime = **hot-window only, snapshot-stable** (never reorder while reading). `[M6]`
- **Reactions ≠ likes** (M6): a quality-signal vocabulary, forward-compatible with the deferred Signals/Resonance economy; exact set **OPEN** (dedicated round). `[M6]`
- **Reactions = separate tables; clicks = one append-only event table.**
- **Tags via join tables only** (postTags/toolTags/resourceTags); **no `tagIds[]` arrays** on any entity. (Categories via arrays — few, single source.)
- **`categories` (topic) and `post.type` (format) are orthogonal** — both exist, single source of truth each.
- **Acquisitions (ownership/quota unit) ≠ Downloads (fetch events).** **Views never create acquisitions** and never burn free-resource quota (DEC-S15 / M10).
- **Resource store = platform-forged free library + optional UGC Constellation pilot** (M10): never serve user reference bytes; rights basis + licence grant required; PDF consumer delivery at launch; Signal only from qualified downloads (contribution-weighted); DMCA-at-launch; kill-gate may disable UGC → in-house only. `[M10]`
- **Campaigns = thin parent now; full commercial subsystem deferred to M11.** `[B2]`
- **Activity ledger (Journal) is foundational** — every user interaction is recorded; reputation/points derive from it in Wave 4. `[B4-revised]`
- **Five separate concepts — never conflated in schema OR product language:** Reaction (expression) · Recognition (accomplishment → **backend** status → public **Awards** + Podium) · Outcome (platform result) · Attribution (ESTIMATED credit — association, not causation) · **Signal** (versioned distribution value from attributed outcomes — **now the PUBLIC earned-value metric, protected by the legitimacy moat not by hiding**; evolved from "system-internal" per DEC-M12-SIGNALS). **Recognition/Awards NEVER feed Signal / Might / reach / ranking / reaction-weight / featuring; Signal never derives from Recognition** (DEC-SIGNAL-FIREWALL, evolved M12). `[reactions-round · M12]`
- **Controlled participation is display-only** — no Createconomy-controlled / operator-curated input (personas, featuring, hero, exploration curation, manual promo) may **manufacture** organic distribution or momentum; it may earn **display visibility** but never feeds a ranking/momentum score. `[M9]`
- **Signals are public; the moat, not secrecy, protects them (M12).** Signal = the public earned-value metric; its integrity is guarded by a hidden per-actor **legitimacy** score [0,1] multiplied into every event (detect-and-**neutralize**, shadow-damp with **no feedback**) — **the one deliberate exception to the transparency spine** (WHAT/WHY public, HOW opaque, so there is no gaming gradient). **Might = √(legitimacy-weighted Reach × Active Signals)** → a downgradable, platform-relative cosmic **Level** ladder; **Levels change, permanent milestone badges don't.** **Recognition** is backend → public **Awards** + Podium; with Signals now public, the firewall's essence holds — **status (Recognition/Awards) never feeds value (Signals/Might) / reach / trust / ranking / featuring, and value never derives from status.** `[M12]`
- **RULE — Public Read Queries:** every query serving both anonymous and member actors must define two explicit branches — an **anonymous-safe view** (redacted/limited fields per the specific entity's public-safe field list) and a **full member view**. This is not a per-screen decision; every future capability with Actor = "anonymous, member" inherits this rule by default. *(Adopted as a standing architectural rule at Wave 2 close, 2026-08-23 — the tension independently surfaced on `/p/[slug]`, `/tools`, and `/tools/[slug]`. Not applied retroactively: Wave 1's screens were anonymous XOR member, never both, so the rule was never triggered there; it governs from Wave 2 onward.)*
- **RULE — Persona genome public-safe allowlist (Wave 5A E-H, 2026-08-24):** same firewall philosophy as CAP-394 sealed economy keys. Public-facing queries for `/personas/[id]` (CAP-180) and `/personas` (CAP-179) may project **only** the public-safe fields enumerated on `personas` / `personaGenomes` below. Sealed fields MUST NEVER appear in any public-facing query response — not as raw genome, not as compiled `systemPrompt`, not as "how this AI thinks" internals. Admin genome console (`/admin/personas/genome`) is the only surface that may read sealed fields.
- Convention: entity names camelCase plural; foreign keys `<entity>Id` / `<entity>Ids`; enums lower_snake literals.
